# NEXUS Intelligence Platform

**Status: v0.1 engineering foundation — not production-ready.**

NEXUS is an offline-first, case-isolated investigation workspace. The initial application uses FastAPI, PostgreSQL, and a Next.js Azerbaijani frontend. It includes session authentication, Case-based permissions, entity records, provenance-linked text evidence, reviewed graph relationships and a local graph transform.

**Security note:** Do not commit real personal data, confidential case material or secrets to this public repository. Production deployment requires additional security hardening.
